Privacidad · Versión de prueba

Actualización: 31 de octubre de 2026.

Where to Go solicita la ubicación del dispositivo solo con permiso. Si se concedió antes, el navegador puede permitir el acceso automático posteriormente. El usuario puede denegar el permiso y seleccionar manualmente una provincia y un municipio.

Cuando se consultan lugares cercanos, las coordenadas y términos de búsqueda se envían al proveedor cartográfico correspondiente. Se utilizan OpenStreetMap, Overpass y Nominatim; si el administrador habilita Google Places, también se pueden realizar consultas a Google Maps Platform. Las políticas de Google incluyen Privacidad de Google y Condiciones de Google Maps.

Los favoritos, borradores de negocios y la lista de municipios se almacenan en el navegador de este dispositivo. Esta versión no tiene cuentas de usuario, no procesa pagos ni publica esos registros para otras personas. Puedes borrar estos datos en la configuración de almacenamiento del navegador.

Antes del lanzamiento comercial se añadirán los datos del responsable del tratamiento, contacto, períodos de retención y derechos aplicables. Este texto es provisional.
